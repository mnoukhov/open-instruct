How compute is counted

Active GPU-hours = the sum of each Beaker attempt’s started-to-ended container runtime × assigned GPUs. Includes initialization, evaluation, failed/repeated work and shutdown; excludes queueing and image pull before container start. This measures resource time, not GPU utilization or FLOPs.

Wall time starts at the first submission and includes scheduling gaps. Every evaluation keeps its real completion time. Repeated steps retain the latest timestamp across W&B attempts.

Older eight-GPU runs use different source/runtime versions. GPU-hours alone do not remove that confound. GPU type is the recorded cohort hardware, not a cross-hardware performance normalization.
